Netflix Clone on Azure - Full Stack Cloud & DevOps Project
---------------------------------------------------------
Project Overview

A full-stack Netflix clone application deployed on Microsoft Azure using Node.js, Express.

js, MongoDB API with Azure Cosmos DB, Azure App Service, Azure Virtual Machines, Virtual

Machine Scale Sets (VMSS), Load Balancer, GitHub Actions CI/CD, and secure Azure 
 
networking components.

Project Architecture

Frontend (React App) ↓ Azure Load Balancer ↓ VM Scale Set (Frontend Servers) ↓ Backend API 

(Azure App Service) ↓ Azure Cosmos DB (MongoDB API)

Secure Administration: VPN Gateway → Jump Box VM → Internal Resources
